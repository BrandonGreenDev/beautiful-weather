# Beautiful Weather Dashboard 🌤️

A modern, sleek weather dashboard built with Vite, React, and TypeScript. Features a stunning 7-day forecast with animated borders and glassmorphism design.

## ✨ Features

- 🎨 **Modern Design**: Glassmorphism cards with animated gradient borders
- 🌈 **Beautiful Animations**: Smooth transitions, border animations, and icon effects
- 📱 **Responsive**: Works perfectly on all devices
- 📍 **Location-Based**: Automatically detects your location
- 🌡️ **7-Day Forecast**: Complete weather forecast for the week
- ⚡ **Fast**: Built with Vite for lightning-fast performance

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/BrandonGreenDev/beautiful-weather.git
cd beautiful-weather
```

2. Install dependencies:
```bash
npm install
```

### Running the App

Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Building for Production

```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## 🎨 Design Features

- **Animated Gradient Borders**: Each forecast card features a beautiful, continuously shifting gradient border
- **Glassmorphism**: Modern glass-effect cards with backdrop blur
- **Custom Weather Icons**: Animated SVG icons for different weather conditions
- **Smooth Transitions**: Fade-in animations and hover effects
- **Dark Theme**: Eye-friendly dark color scheme with vibrant accents

## 🛠️ Tech Stack

- **Vite**: Next-generation frontend tooling
- **React 19**: Latest React with hooks
- **TypeScript**: Type-safe code
- **Open-Meteo API**: Free weather data provider (no API key required)
- **CSS3**: Modern CSS with animations and gradients
